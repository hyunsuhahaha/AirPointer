# 브라우저와 Windows 앱 기능 비교

공모전 제출과 공개 체험의 기본 경로는 브라우저입니다. 화면 공유 후 작은 창에서 모드를 고르고 AI 내보내기를 누르면 기존 에이전트에게 전달할 자료와 프롬프트가 생성됩니다.

| 기능 | 브라우저 | Windows 앱 |
| --- | --- | --- |
| 화면 캡처 | 사용자가 허용한 화면·창·탭 | 로컬 데스크톱 |
| 최근 장면 | 브라우저 메모리의 제한된 순환 버퍼 | 로컬 화면 순환 버퍼 |
| 실행 버튼 | 웹 화면과 지원 브라우저의 Document PiP | 전역 단축키 `Ctrl+Alt+S/D/R` |
| AI 전달 | 기록 탭에 접근 가능한 에이전트가 버퍼를 직접 읽음, 또는 `context.md` + 원본 이미지 6~12장 폴더를 첨부. PDF 한 개는 선택 형식 | 선택한 Codex·Claude Desktop 대화 |
| 행동 맥락 | 관측된 화면 변화 시각·영역, 화면·녹화 기록 | 선택 텍스트, 창·클릭 이력, 선택적 클립보드 이력 |
| 설치 | 필요 없음 | Windows 앱 필요 |

전체 접근은 현재 기록 탭에서 JavaScript를 실행할 수 있는 에이전트에게만 유효합니다. 탭을 닫거나 화면 공유를 중지하면 읽기 통로가 닫힙니다. 원본 파일 형식은 최초 한 번 상위 폴더 쓰기 권한을 받고 이후 그 안에 `Export-*` 폴더를 만듭니다. 일반 웹페이지는 Explorer를 자동으로 열거나 파일 여러 개를 자동 선택할 수 없습니다.
