# 브라우저와 Windows 앱 기능 비교

공모전 제출과 공개 체험의 기본 경로는 브라우저입니다. 화면 공유 후 작은 창에서 모드를 고르고 AI 내보내기를 누르면 기존 에이전트에게 전달할 자료와 프롬프트가 생성됩니다.

| 기능 | 브라우저 | Windows 앱 |
| --- | --- | --- |
| 화면 캡처 | 사용자가 허용한 화면·창·탭 | 로컬 데스크톱 |
| 최근 장면 | 브라우저 메모리의 제한된 순환 버퍼 | 로컬 화면 순환 버퍼 |
| 실행 버튼 | 웹 화면과 지원 브라우저의 Document PiP | 전역 단축키 `Ctrl+Alt+S/D/R` |
| AI 전달 | Manual 이미지 드래그, 20분 Agent Link, 또는 `context.md`·`events.json`·이미지가 든 Local Folder | 선택한 Codex·Claude Desktop 대화 |
| 행동 맥락 | 관측된 화면 변화 시각·영역, 화면·녹화 기록 | 선택 텍스트, 창·클릭 이력, 선택적 클립보드 이력 |
| 설치 | 필요 없음 | Windows 앱 필요 |

Manual은 대표 화면과 펼친 사이 화면을 브라우저 기본 이미지 드래그로 전달합니다. 스크립트가 만든 메모리 `File`은 Chrome이 실제 드롭에서 파일명 문자열로 바꾸므로 사용하지 않습니다. Agent Link는 localhost 접근 대신 배포 사이트의 비공개 토큰 URL을 사용합니다. Local Folder는 최초 한 번 상위 폴더 쓰기 권한을 받고 이후 그 안에 `Context-*` 폴더를 만듭니다. 일반 웹페이지는 Explorer를 자동으로 열거나 파일 여러 개를 자동 선택할 수 없습니다.
