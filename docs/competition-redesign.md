# 무설치 출품 경험 개편 — 2026-09-07

제품의 중심은 **놓친 순간을 질문하고, 화면 근거를 확인하고, 사건 기록을 가져가는 것**이다.
기존 네이티브 확장 기능은 유지하되 브라우저 기본 진입에서 실행하거나 조회하지 않는다.

## 구현한 흐름

1. 첫 화면의 `30초 체험하기` → Northstar 샘플 상점에서 주문 3개 중 하나를 선택한다.
2. 수량(1~3개)과 결제 수단(카드·간편결제·계좌)을 직접 바꾸고 `결제 요청`을 누른다.
   카드 인증 시간 초과, 간편결제 한도 초과, 계좌 정상 승인으로 결과가 달라진다.
   응답 알림은 약 650ms 후 사라진다. 화면은 재생 영상이 아니라 상태가 변하는 실제 Canvas UI다.
   샘플임을 표시하며 실제 금액 청구나 외부 서비스 조작은 없다.
3. 질문을 보내면 실제 `/api/analyze`를 호출한다. 정답을 하드코딩하지 않는다.
4. 대표 프레임과 추가 조회 프레임을 작업대에 표시한다. 사용자가 프레임을 고르면 자동으로 선택을 덮어쓰지 않는다.
5. 분석이 완료되면 사건 작업대를 중심 화면으로 전환한다. 제목, 답변, 확인한 사실,
   가능한 원인(추정), 다음 확인 사항, 시점별 근거를 표시한다.
6. 근거를 받으면 되감기(1.35초) → 정지(0.42초) → 실제 근거 영역 확대(0.9초) → 설명 연결로 이어진다.
   근거를 선택하면 해당 장면의 연출을 다시 실행한다. `전후 원본 보기`로 기존 타임머신을 연다.
7. 선택한 근거를 포함한 텍스트 복사 또는 단일 HTML 보고서 다운로드를 제공한다.
8. `질문 수정`, `새 체험`, `내 화면에서 사용하기`로 다음 작업을 이어간다.

30초는 체험 동선을 설명하는 목표이며 모델 응답 시간을 보장하는 문구가 아니다.
시연 화면에도 AI 분석 시간 별도를 표시한다.

## 실제 공유와 데이터 수명

- 화면 공유 권한은 실제 사용에서만 요청한다. 샘플은 PiP 권한도 요청하지 않는다.
- PiP 없이 메인 화면에서 현재 화면·리플레이·영역 분석을 사용할 수 있다.
- 기본 브라우저 경로는 카메라를 실행하거나 로컬 Agent 목록을 조회하지 않는다.
- Screen Memory 자동 저장은 확장 기능 안의 별도 영구 보관 옵션으로 이동했다.
  기본값은 꺼짐이며, 브라우저 기본 모드에서는 켜져 있던 옵션도 자동 저장을 실행하지 않는다.
- 공유 중지는 순환 버퍼와 재시도 캡처를 비우고 진행 중인 분석을 취소한다.
  이미 완료된 분석 결과와 직접 저장한 보고서는 별도로 남는다.
- 같은 질문의 분석 실패는 고정한 초기 프레임·메타데이터·리플레이 캡슐을 유지해서 재시도한다.
  질문·분석 방식·공유 소스·구간이 달라지면 새 캡처를 사용한다.
- API 요청 한 번의 대기 상한은 90초다. 실패를 정답으로 바꾸거나 자동 재전송하지 않는다.

## 보고서와 개인정보

보고서에는 모델의 HTML을 삽입하지 않는다. 모든 텍스트를 이스케이프하고 이미지에는
PNG/JPEG/WebP의 base64 data URL만 허용한다. 외부 리소스와 스크립트를 차단하는 CSP도 포함한다.
개인정보 보호가 켜져 있었다면 화면 근거와 보고서는 API에 전송했던 가림 사본을 사용한다.
근거 타임머신의 전후 장면은 기존처럼 로컬 원본이며 추가 전송하지 않는다.
OCR은 완벽한 민감정보 탐지를 보장하지 않으므로 수동 영역 가림과 저장 전 확인을 유지한다.

## 검증

- 타입 검사, ESLint, 프로덕션 빌드.
- 기존 단위 테스트와 보고서 HTML 주입·외부 이미지 차단 테스트.
- Chrome E2E: 로컬 Agent 요청 없음, 샘플 조작, API 실패 후 재시도, 추가 프레임 조회,
  근거 타임머신, 다운로드에 실제 전송 이미지 포함, 1440/768/390px 레이아웃.
- PiP 자동 열기 테스트는 합성 화면 공유와 테스트 창을 사용한다.
- 실제 모델 검증 1회: 대표 6장 → 추가 조회 후 9장, 3-D Secure 인증 시간 초과를 찾고
  구조화된 사건 카드와 근거 3개 반환. 단일 성공 사례이며 일반적인 정확도·지연 보장이 아니다.

실제 모델 검증은 `AIRPOINTER_LIVE_ANALYSIS=1`을 지정하고
`npx playwright test tests/competition-live.e2e.ts --reporter=line`으로 재실행한다.
비용이 발생하는 검증이므로 기본 테스트 실행에서는 건너뛴다.

## 제출 전 외부 환경에서 확인할 사항

- 배포 URL, 서버 API 키, 실제 브라우저 화면 공유 권한과 OS의 PiP 동작.
- 대회 공식 심사 기준·마감일, 동시 사용자 수에 따른 API 예산 및 서버 제한.
- 시나리오별 반복 실측으로 근거 발견 성공률·분석 지연 분포 측정.

## 직접 조작·되감기 품질 개편 — 2026-09-08

- `InteractiveCase`: 실제 화면 상태가 바뀔 때 사용자가 보는 Canvas를 그대로 JPEG로 기록한다.
  조작·응답이 발생한 시각을 보존하며 고정 -6초 오류 프레임을 생성하는 기존 시나리오를 사용하지 않는다.
- `InteractiveReplay`: 최근 60초 안의 실제 상태 이력을 조회한다. 조회 시점에 실제로 표시됐던 상태를 반환하고
  기록 시작 전 요청에는 빈 결과를 반환한다. 영상을 통째로 전송하지 않는다.
- `ReplayCinema`: 실제 조회 프레임을 시간순으로 정렬하고, 모델이 선택한 근거로 이동한다.
  영역은 기록한 알림 위치 또는 실제 확대 요청이 있는 경우에만 강조한다. 전체 화면 근거에 임의 박스를 만들지 않는다.
- 타임라인을 조작하면 예약된 연출을 취소한다. 다시 보기 또는 근거 선택으로만 자동 연출을 재개한다.
  모션 감소 설정에서는 시간 이동·확대 애니메이션 없이 즉시 같은 근거를 보여준다.
- 카드/계좌 실제 API 검증: 인증 시간 초과와 정상 승인을 각각 구분했다. 해당 실행의 분석 시간은 각 약 9.3초였으며
  요청 프레임은 카드 최종 10장, 계좌 최종 6장이었다. 소수의 개발 검증이며 성능 보장이 아니다.
- 브라우저 테스트는 주문/수량/결제 수단 변경이 실제 이미지에 반영되는지, 재시도, 확대,
  수동 탐색 시 자동 연출 중단, 키보드·모바일·모션 감소, 보고서의 전송 이미지 일치를 확인한다.

결제 외 개발·재고·회의는 기존 샘플 재생 시나리오로 남아 있다. 이번 직접 조작 개편의 대상은 결제 운영 체험이다.
영구 공유 URL은 추가 확장 범위다.
